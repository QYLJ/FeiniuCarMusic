1. 新增歌曲缓存设置：默认 512 MB，可按车机存储调整为 64 MB–64 GB，支持查看用量与清理，常听歌曲再次播放复用完整缓存。
2. 新增切歌淡入淡出，默认 0.5 秒，可关闭或调整至 2 秒；保持导航播报期间的降音量行为。
3. 顺序播放和列表循环提前准备后续歌曲，默认 2 首，可选 1–3 首或关闭，减少未缓存歌曲切换时的等待。
4. 新增明亮、暗色和跟随车机日夜模式，在设置中选择，适配页面、歌词、播放控制和登录界面。
5. 新增加密保存账户和免密切换，登录页支持添加、删除，设置提供账户管理入口；切换时隔离旧播放、缓存和请求。
6. 修复大量歌曲队列保存导致的内存溢出，以及播放页关闭后的延迟回调异常，改善低内存车机稳定性。
7. 改善 FN ID 在移动网络下仍连接旧内网地址的问题，连接失败时重新选择可用线路。
8. Android 4/5 原音频增加支持 Range 的流式读取和完整缓存复用，失败时保留原文件及自动转码兼容路径。
