# 飞牛车载音乐

面向 Android 4.0（API 14）及以上横屏车机的独立 fnOS 音乐客户端。当前版本为 `0.3.14-streaming`。

界面参考飞牛音乐官方 Web 客户端的深紫黑背景、红色强调色、左侧导航、首页快捷卡片和常驻播放栏，并针对不同尺寸的横屏车机采用约束式自适应排版。安装图标采用飞牛音乐官方客户端的视觉资产，并提供 Android 4.0 可识别的多密度 PNG 资源。本项目不是飞牛官方客户端。

`0.3.10` 统一导航、首页入口、收藏与播放控制的图标，调整为柔和的深色卡片与红色播放主按钮；封面支持圆角及缺失封面占位，登录表单可滚动，播放器进度条统一为红色细线。曲库导航、标题和首页卡片按屏幕宽高调整尺寸。

`0.3.11` 将歌单、曲库、收藏、搜索和分类详情的歌曲请求改为每批 500 首，超过一批可继续滚动加载，播放时将已加载歌曲完整加入队列。新版检查结果会保存到本机，登录页、曲库页和播放页恢复前台时自动检查并展示可用新版及更新内容；选择“稍后”后本次运行不重复提醒，重新启动应用仍会提醒未安装的新版。

`0.3.12` 将歌曲列表改为每批 500 首自动连续加载，直到全部加载完成，无需滚动触发。第一批显示后即可播放，进入播放页后后续批次仍会补入同一个播放队列，保留当前歌曲、位置和播放状态。加载失败时保留已有歌曲，点击加载状态可继续重试；服务器重复返回同一批歌曲时停止，避免无限请求。

`0.3.13` 加入 NAS 端 MP3 / FLAC 转码。点击播放页的音质标签可选“自动兼容”“原始音质”“NAS 转码 MP3”“NAS 转码 FLAC”，选择会保存，切换时保留当前歌曲与播放位置。自动模式优先使用原音频，对已知不兼容的格式或原音频解码失败尝试 NAS MP3；用户明确选择的模式会按选择执行，失败时显示原因。长按音质标签可查看声音诊断。

`0.3.14` 在音质对话框加入“MP3 码率”，提供 128 / 192 / 256 / 320 kbps，默认 192 kbps，播放标签显示实际音频帧计算的码率。Android 6.0 / API 23 及以上支持边转码、边下载、边播放，包括 7.1.x / API 25；读到未到达的数据时等待缓冲，只有整首真正结束才返回 EOF。Android 4.x / 5.x 保留完整文件兼容播放。渐进播放中跳转会保留后台下载，完整后重新准备并跳转，避免部分原生播放器对未知时长流快进报错。

## 已实现功能

- FN ID（FN Connect）、内网或外网 fnOS 地址登录
- FN ID 自动解析内网、FN Connect 中继和公网候选线路，并优先选择可用线路
- 裸地址自动补全 HTTP 和默认端口
- 首页：漫游、收藏、最近播放、音乐库、最近添加
- 歌曲每批 500 首自动加载至全部完成、歌曲/歌手/专辑搜索和全部播放
- 专辑、歌手、音乐风格、歌单浏览及详情歌曲
- 收藏/取消收藏（点击列表爱心或播放器爱心）
- 本机最近播放记录
- 大封面播放页、按时间轴连续滚动并自动适配长行的 LRC 歌词、实际编码/位深/采样率显示
- 播放队列、队列选曲、上一首/下一首、进度跳转
- 顺序播放、列表循环、单曲循环、随机播放
- 前台播放服务及蓝牙/标准方向盘媒体按键
- Android 5+ MediaSession 与 Android 4 RemoteControlClient 双通道车机控制
- NAS 端 MP3 / FLAC 立体声转码、MP3 四档码率、自动兼容与实际播放格式显示
- Android 6+ 安全渐进播放，收到可解码的真实音频后开播
- 声音诊断：系统版本、媒体音量、音频焦点及蓝牙媒体状态
- 应用内在线检查、下载、SHA-256 校验与安全安装更新
- 自动新版提示与更新内容展示，后台检查结果在返回页面时继续提示
- 登录前也可检查更新；使用 AList 访客读取更新清单与按文件获取签名下载链接
- 512 MB 私有缓存与断流 Range 续传

编码转换在 NAS 完成，客户端只下载和重组音频帧。API 23+ 使用可阻塞的 MediaDataSource，只向播放器交付已经写入的真实字节，后段在后台持续准备；不把不断增长的普通文件直接交给播放器，也不预分配空白文件区。旧系统继续完整下载后用文件 FD 播放。原音频、不同转码格式和 MP3 码率分别缓存，完成后可复用。

首次准备耗时受 NAS 转码速度、网络和系统播放器预读影响，不能保证每首都在第一片时开播。未知时长的流首次播放可显示 NAS 歌曲时长；下载中拖动进度条会等待完整文件再跳转，暂停/恢复会保留当前下载。切换音质或码率保留非零播放位置时也先准备完整文件以可靠恢复位置。

已修复 Android 4.0.4 对 FLAC 文件头的兼容问题，并处理音频焦点拒绝、降音量后恢复及加载期间短暂失焦。API 25 的实际服务渐进播放、下载中跳转、暂停恢复和失败/取消验证，以及旧系统测试见 `TEST_REPORT.md`。API 25 原生测试镜像为 Android 7.1.1，不能当成 7.1.2 车机试听；真实车机的蓝牙、音源、DSP 与扬声器仍需设备验证。格式边界和排查方法见 `AUDIO_COMPATIBILITY.md`。

FN Connect 当前使用的 HTTPS 证书链和 TLS 协议超出了部分 Android 4 系统的原生能力。本项目在 Android 4.x 上内置 Conscrypt 2.5.3，并以“系统证书库 + USERTrust ECC + ISRG Root X1”的组合方式执行完整证书校验，不会跳过主机名或证书验证。

## 构建

推荐使用 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0：

```powershell
.\gradlew.bat assembleDebug
```

本机还提供了不依赖 Gradle 守护进程的后备构建脚本：

```powershell
.\tools\manual-build.ps1
```

后备构建产物位于 `.manual-build/app-debug.apk`。完整测试结果见 `TEST_REPORT.md`。

## 登录地址

可以输入 FN ID（例如 `myfnid`）、`192.168.1.100`、`http://192.168.1.100:5666` 或 `example.com:8326`。未填写协议时自动使用 HTTP；未填写端口时自动使用 5666。

使用 FN ID 前，需要先在 fnOS 中开启 FN Connect。FN ID 只负责查找 NAS，本客户端使用飞牛音乐的账号密码登录接口。旧版音乐可能使用 fnOS 用户名和密码；新版音乐同时提供音乐账号密码登录与 NAS 账号网页授权登录，这两个入口不能直接等同。本客户端目前未实现 NAS 网页 OAuth 授权流程。

“FN ID 已找到”仅说明目录查询成功，不代表音乐线路可达。客户端会先按官方连接页的流程建立 FN Connect 网关会话，保存该线路的路由 Cookie，再请求音乐 API；应用进程重启后会重新建立网关会话，继续使用已保存的音乐登录会话。网关初始化只发送 GET，不携带音乐账号、密码或 Token，并限制跳转到同一站点。

客户端会区分连接超时、DNS 失败、HTTPS 校验失败、HTTP 错误和 FN Connect 跳转到检测网页；配置接口要求鉴权时仍继续一次正式登录。若所有线路均不可用，请在同一设备、同一网络上用浏览器访问官方音乐页面，或填写已配置好的外网域名与端口。

登录阶段返回 `unauthorized` 时，提示账号鉴权被拒绝并保留错误码，不再把尚未登录的请求描述为“登录已失效”。此时应确认使用的是音乐密码登录入口对应的账号；若官方页面要求 NAS 授权，请先在官方页面完成授权并确认可用的音乐账号登录方式。

本项目调用的是非公开的飞牛音乐接口，fnOS 后续升级可能需要同步适配。
