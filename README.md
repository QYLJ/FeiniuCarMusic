# 飞牛车载音乐

`0.3.19-playback-fixes / 26` 已于 2026-11-17 发布至 AList 更新通道。封面改为临时文件校验、采样解码与按内存限额缓存，切歌时旧音频连接在后台清理。新增 NAS fMP4 Opus 到 Ogg Opus 的无损封装转换，保留预跳过与尾部裁剪，实际播放仍取决于车机的 Opus 解码支持。

“设置 → 缓存目录（TF 卡 / U 盘）”可选择检测到的应用专用存储目录，旧车机也可输入可写的挂载路径；先验证写入再保存，拔出后新请求回退内部缓存。旧目录中的缓存保留，切回可继续使用。Android 新版本应选择列表中的应用专用目录，不申请全盘管理权限。

“设置 → 导航播报处理”默认在导航临时占用或请求降低音乐音量时暂停音乐，焦点归还后恢复；支持混音的车机可改为降低音量。用户手动暂停、停止、切换账户或永久失焦后不会自动恢复。活跃播放服务可在系统回收后按上次位置恢复；厂家强制清理和未发送音频焦点通知的导航仍需在实际车机验证。

面向 Android 4.0（API 14）及以上横屏车机的独立 fnOS 音乐客户端。当前版本为 `0.3.20-login-fixes`（versionCode 27）。

界面参考飞牛音乐官方 Web 客户端的深紫黑背景、红色强调色、左侧导航、首页快捷卡片和常驻播放栏，并针对不同尺寸的横屏车机采用约束式自适应排版。安装图标采用飞牛音乐官方客户端的视觉资产，并提供 Android 4.0 可识别的多密度 PNG 资源。本项目不是飞牛官方客户端。

`0.3.10` 统一导航、首页入口、收藏与播放控制的图标，调整为柔和的深色卡片与红色播放主按钮；封面支持圆角及缺失封面占位，登录表单可滚动，播放器进度条统一为红色细线。曲库导航、标题和首页卡片按屏幕宽高调整尺寸。

`0.3.11` 将歌单、曲库、收藏、搜索和分类详情的歌曲请求改为每批 500 首，超过一批可继续滚动加载，播放时将已加载歌曲完整加入队列。新版检查结果会保存到本机，登录页、曲库页和播放页恢复前台时自动检查并展示可用新版及更新内容；选择“稍后”后本次运行不重复提醒，重新启动应用仍会提醒未安装的新版。

`0.3.12` 将歌曲列表改为每批 500 首自动连续加载，直到全部加载完成，无需滚动触发。第一批显示后即可播放，进入播放页后后续批次仍会补入同一个播放队列，保留当前歌曲、位置和播放状态。加载失败时保留已有歌曲，点击加载状态可继续重试；服务器重复返回同一批歌曲时停止，避免无限请求。

`0.3.13` 加入 NAS 端 MP3 / FLAC 转码。点击播放页的音质标签可选“自动兼容”“原始音质”“NAS 转码 MP3”“NAS 转码 FLAC”，选择会保存，切换时保留当前歌曲与播放位置。自动模式优先使用原音频，对已知不兼容的格式或原音频解码失败尝试 NAS MP3；用户明确选择的模式会按选择执行，失败时显示原因。长按音质标签可查看声音诊断。

`0.3.14` 在音质对话框加入“MP3 码率”，提供 128 / 192 / 256 / 320 kbps，默认 192 kbps，播放标签显示实际音频帧计算的码率。Android 6.0 / API 23 及以上支持边转码、边下载、边播放，包括 7.1.x / API 25；读到未到达的数据时等待缓冲，只有整首真正结束才返回 EOF。Android 4.x / 5.x 保留完整文件兼容播放。渐进播放中跳转会保留后台下载，完整后重新准备并跳转，避免部分原生播放器对未知时长流快进报错。

`0.3.15` 新增侧栏显示与字体设置，优化小屏排版，播放页使用简洁音质标签与纯图标控制栏。修复连续导航临时失焦后持续暂停，焦点归还后恢复；允许混音期间保持降低音量播放。声音诊断可复制最近的音频焦点事件，用于排查高德与不同车机的信号差异。

`0.3.16` 将播放控制收拢为有宽度上限的圆角组合，播放键居中、队列独立，窄屏调整间距并保留触控面积。提高封面背景可见度，减淡遮罩；封面按尺寸缓存，完整下载校验后再解码，避免缩略图被放大或中断图片进入缓存。同期纳入转码连接复用、临时 404 有限等待和准备阶段耗时诊断。每次打包交付版本化更新 APK 及对应 `update.json`。

`0.3.17` 将歌单列表放到侧栏“歌单”下方，右侧直接显示所选歌曲，支持分页、切换与重试；低高度屏幕可分别滚动导航和歌单。播放控制图标和触控区域增大，间距适度放宽并限制整组宽度。下载按实际歌曲隔离，完整音频就绪后不再等待 NAS 结束会话回复，声音诊断补充各阶段耗时。Android 4/5 仍采用完整文件播放；实机首播表现还受 NAS、线路和系统播放器影响。

编码转换在 NAS 完成，客户端只下载和重组音频帧。API 23+ 使用可阻塞的 MediaDataSource，只向播放器交付已经写入的真实字节，后段在后台持续准备；不把不断增长的普通文件直接交给播放器，也不预分配空白文件区。旧系统继续完整下载后用文件 FD 播放。原音频、不同转码格式和 MP3 码率分别缓存，完成后可复用。

首次准备耗时受 NAS 转码速度、网络和系统播放器预读影响，不能保证每首都在第一片时开播。未知时长的流首次播放可显示 NAS 歌曲时长；下载中拖动进度条会等待完整文件再跳转，暂停/恢复会保留当前下载。切换音质或码率保留非零播放位置时也先准备完整文件以可靠恢复位置。

已修复 Android 4.0.4 对 FLAC 文件头的兼容问题，并处理音频焦点拒绝、降音量后恢复及加载期间短暂失焦。API 25 的实际服务渐进播放、下载中跳转、暂停恢复和失败/取消验证，以及旧系统测试见 `TEST_REPORT.md`。API 25 原生测试镜像为 Android 7.1.1，不能当成 7.1.2 车机试听；真实车机的蓝牙、音源、DSP 与扬声器仍需设备验证。格式边界和排查方法见 `AUDIO_COMPATIBILITY.md`。

FN Connect 当前使用的 HTTPS 证书链和 TLS 协议超出了部分 Android 4 系统的原生能力。本项目在 Android 4.x 上内置 Conscrypt 2.5.3，并以“系统证书库 + USERTrust ECC + ISRG Root X1”的组合方式执行完整证书校验，不会跳过主机名或证书验证。

## 歌曲缓存设置（0.3.18）

在“设置 → 歌曲缓存”调整容量：提供 64 / 128 / 256 / 512 MB 和 1 / 2 / 4 / 8 / 16 GB 档位，也可按 MB 自定义 64 MB–64 GB。默认 512 MB，选择会保存，不会预先占用整个容量。页面显示已用空间、完整歌曲数和剩余存储，可清理未在使用的歌曲缓存。

完整缓存优先用于再次播放，原音频、转码格式和 MP3 码率分开存储。FN ID 登录按同一 NAS 和账号识别缓存，内外网线路切换不重复下载，旧线路缓存可自动迁移。后台按最近使用顺序清理，正在播放或下载的文件保留至释放；因此正在使用的单曲大于上限时可暂时超过设置值。歌曲缓存使用存储空间，系统在存储压力下也可能回收应用缓存。

## 切歌、预加载、主题与账户（0.3.18，2026-10-20）

在“设置 → 播放”调整切歌淡入淡出和列表预加载。淡入淡出默认 500 ms，可关闭，或选择 250 / 500 / 1000 / 1500 / 2000 ms。手动切歌先淡出，下一首就绪后淡入；自然播完在结尾淡出。导航允许混音时继续叠加降音量，暂停或停止会取消待执行的切歌。

预加载默认提前准备后续 2 首，可关闭或选择 1–3 首。顺序播放和列表循环使用当前音质、MP3 码率及缓存上限，单线程准备后续歌曲；点击正在预加载的歌曲复用同一下载，已完成的歌曲直接读取缓存。随机和单曲循环不猜测后续曲目；更换队列、音质或账户后取消过时任务。预加载会使用当前网络，未准备完成时仍可能等待 NAS、网络或系统解码，不能保证完全无缝切歌。

在“设置 → 显示 → 明暗主题”选择明亮、暗色或跟随车机。默认跟随 Android 系统的日夜模式，系统没有报告日夜状态时采用暗色；未向 Android 提供日夜信号的车机可手动选择。页面、歌词、播放控制、登录和弹窗使用对应配色，设置不会修改车机系统主题。

在“设置 → 应用 → 账户管理与切换”进入登录页。首次用密码登录并勾选“加密保存此账户”，以后点击已保存账户即可重新认证，无需输入密码；可添加或确认删除本机保存的账户，最多 20 个。已有旧版登录不会凭空取得历史密码，需先保存一次。切换认证失败保留当前会话，成功后停止旧播放并清理旧队列和本机最近播放记录；歌曲缓存按 NAS 和账号隔离。免密切换仍需要 NAS 可访问。

账密使用随机 IV 的 AES-256 加密及 HMAC-SHA256 完整性校验；Android 4.3 / API 18 及以上通过系统 AndroidKeyStore 包装密钥，API 14–17 使用应用私有目录密钥，关闭应用备份。界面和日志不显示保存的密码。加密保存不可用时会明确提示，当前登录仍可使用。删除本机保存项不删除 NAS 账户。

## 登录地址

0.3.20 支持粘贴飞牛音乐网页地址。仅填域名时会先探测 HTTP 5666，再根据需要尝试 HTTPS 443。填写完整协议和端口可直接指定入口。Android 5/6 保留系统证书校验，并补充旧系统可能缺少的两个根证书。FN Connect 目录服务临时出错时会继续尝试备用入口。日期错误、证书链不受信任、DNS 失败、内网端口不通和音乐账号被拒绝会分别提示。

已发布的 0.3.19 可以输入 FN ID（例如 `myfnid`）、`192.168.1.100`、`http://192.168.1.100:5666` 或 `example.com:8326`。未填写协议时自动使用 HTTP；未填写端口时自动使用 5666。

使用 FN ID 前，需要先在 fnOS 中开启 FN Connect。FN ID 只负责查找 NAS，本客户端使用飞牛音乐的账号密码登录接口。旧版音乐可能使用 fnOS 用户名和密码；新版音乐同时提供音乐账号密码登录与 NAS 账号网页授权登录，这两个入口不能直接等同。本客户端目前未实现 NAS 网页 OAuth 授权流程。

“FN ID 已找到”仅说明目录查询成功，不代表音乐线路可达。客户端会先按官方连接页的流程建立 FN Connect 网关会话，保存该线路的路由 Cookie，再请求音乐 API；应用进程重启后会重新建立网关会话，继续使用已保存的音乐登录会话。网关初始化只发送 GET，不携带音乐账号、密码或 Token，并限制跳转到同一站点。

客户端会区分连接超时、DNS 失败、HTTPS 校验失败、HTTP 错误和 FN Connect 跳转到检测网页；配置接口要求鉴权时仍继续一次正式登录。若所有线路均不可用，请在同一设备、同一网络上用浏览器访问官方音乐页面，或填写已配置好的外网域名与端口。

登录阶段返回 `unauthorized` 时，提示账号鉴权被拒绝并保留错误码，不再把尚未登录的请求描述为“登录已失效”。此时应确认使用的是音乐密码登录入口对应的账号；若官方页面要求 NAS 授权，请先在官方页面完成授权并确认可用的音乐账号登录方式。

本项目调用的是非公开的飞牛音乐接口，fnOS 后续升级可能需要同步适配。

0.3.18（2026-10-20）修复：FN ID 登录在内网线路失效后重新解析候选线路，切到移动网络时跳过旧内网地址并尝试可用外网或中继；线路恢复重用现有音乐会话，不读取或重发保存的密码。手动填写内网地址的用户在移动网络下会得到使用 FN ID / 外网地址的明确提示。播放队列改为后台逐条保存，进度更新只写索引和位置；旧队列自动迁移。播放页关闭后忽略晚到回调。Android 4/5 原音频增加 HTTP 流式读取、Range 定位、完整缓存复用与文件回退，详见 `AUDIO_COMPATIBILITY.md`。
